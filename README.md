# 生态系统模拟器 · Ecosystem Lab

一个单文件、零依赖的 2D 生态模拟器。在浏览器里直接打开 `index.html` 即可运行。

**核心设计原则：能量是唯一货币。** 没有为每种生物写死的规则，所有个体共享同一套
能量代谢、取食、捕食、繁殖、死亡逻辑，物种差异全部来自参数表与基因。因此
捕食者-猎物振荡、营养级联、季节性消长等现象是**涌现**出来的，而不是被编排的。

---

## 一、怎么用

打开 `index.html`，左栏是控制台，右栏是实时数据。

| 操作 | 说明 |
|:---|:---|
| 播放 / 单步 / 重置 | 控制模拟推进 |
| 速度 0.25× ~ 16× | 加速观察长期演化 |
| 投放 / 猎杀 / 放火 / 浇灌 | 鼠标直接干预世界 |
| 气候滑块 | 降雨、温度、年长、变异率、代谢系数、生产力等 |
| 预设 | classic（经典）/ boom（丰饶）/ drought（干旱） |

快捷键：`空格` 暂停 · `R` 重置 · `1`~`6` 选择投放物种。

## 二、模拟了什么

### 六个物种，四个营养级

| 层级 | 物种 | 角色 |
|:---|:---|:---|
| 生产者 | 草本 / 灌木 | 两套独立植被，逻辑斯蒂增长 + 邻格蔓延 |
| 初级消费者 | 🐜 昆虫、🐇 兔、🦌 鹿 | 兔专食草本，鹿偏食灌木（生态位分化） |
| 次级消费者 | 🐦 鸟、🦊 狐 | 鸟食虫+灌木；狐为杂食性捕食者 |
| 顶级捕食者 | 🐺 狼 | 捕鹿/兔/狐 |

### 采用的生态学规律

- **Kleiber 定律**：代谢 ∝ 体型^0.75，大动物单位体重更省能
- **进食速率 ∝ 体型**（而非 ^0.67）：若吃得比代谢涨得快，大动物会变成无敌，违背 Kleiber
- **Type III 功能反应**：猎物密度越低越难被找到，形成低密度避难所
- **幼体脆弱期**：幼体被捕获门槛远低于成体，成体靠体型威慑自保
- **季节循环**：温度/降雨按正弦变化，驱动植被生产力起伏

## 三、当前状态（诚实说明）

### 已达成并验证

| 项目 | 结果 |
|:---|:---|
| **六物种长期共存（classic）** | **12/12 次 · 900 秒模拟**，每物种存活率 12/12 |
| **六物种长期共存（boom）** | **12/12 次 · 900 秒模拟**，每物种存活率 12/12 |
| **能量守恒** | 残差 **−8 E**（光合输入约 80 万 E，相对误差 ~0.001%） |
| **回归测试** | `test.mjs` **63 项全部通过** |
| 性能 | 约 1700 步/秒（700+ 个体） |

### 能力边界

- **drought（干旱）预设下狼可能灭绝（3/12）**。这在生态学上是合理的——
  干旱导致植被稀疏、猎物减少，顶级捕食者承受最大的食物压力。**我们不认为这是缺陷**，
  它反映真实的气候响应；但如果你需要干旱下也稳定，可以调高降雨滑块。
- 捕食者的搜索行为是简化的（方向持久的随机搜索，无嗅觉/追踪机制）。
- 未建模：疾病、空间迁徙、年龄结构细化、种内竞争。

## 四、开发中修掉的关键问题

这些是真实发现并修复的，记录在此以便理解代码中的注释：

1. **能量守恒漏洞**：取食超出能量上限的部分被 `Math.min` 静默截断，
   但植被已被扣除 → 能量凭空蒸发。实测守恒误差高达 **264%**。
   修正后残差归零。**这是最早、也最影响后续所有调参的问题。**

2. **成年鹿体型威慑失效**：捕食门槛为 `猎物体型 × 1.15`，狼出生体型 2.6，
   而鹿为 2.0 → `2.6 ≥ 2.30` 恒成立，**成年鹿毫无威慑力**，鹿群被清零。
   改为成年 1.40 / 幼体 1.05 后，鹿 900 秒存活率 0/5 → **12/12**。

3. **种群曲线永远空白**：`sampleHistory` 只在重置时被调用一次，
   图表数据点永远只有 1 个，曲线画不出来。改为在 `step()` 中每 0.5 秒采样。

4. **暂停时上帝工具失效**：放火/浇灌依赖空间哈希，而哈希只在 `step()` 中重建，
   暂停时哈希过期 → 工具静默无效。改为工具调用前重建哈希。

5. **捕食者"瞎转"**：找不到猎物时漫游转向幅度过大，轨迹退化为原地乱转，
   狼 **74.9%** 的生命耗在无收益漫游（−2.39 E/s）。收窄转向后六物种共存率 0/12 → 12/12。

6. **中层捕食者被夹杀**：狐上有狼捕食、下无稳定猎物，且自身不能吃植物兜底，
   必然灭绝（实测 92 秒饿死）。修复：加入杂食兜底 + 降低狼对狐的食性权重。

## 六、技术要点

- 世界 1600×1000，格子 16px（100×62），空间哈希边长 90px 做 O(n) 邻域查询
- 固定时间步 `SIM_DT = 1/30`，与帧率解耦
- 渲染用 3 倍超采样离屏 canvas 生成地形贴图，缩放/平移时保持清晰
- 引擎内部通过 `globalThis.__E` 导出句柄，供测试直接驱动（不依赖 UI）
